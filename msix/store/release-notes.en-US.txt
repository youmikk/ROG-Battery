New
- Added Logitech HID++ 1.0 / 2.0 and standard HID battery queries, pending per-model hardware validation.
- Supported Logitech mice expose their actual onboard DPI stages, including the fifth stage, for switching from the main window or tray.
- Added read-only Rapoo nRF54L battery and current DPI queries, with 77 official driver model entries pending hardware validation.
- Added VGN V98 Pro V3 battery queries; wired readings have been verified on hardware.
- Added a device compatibility feedback entry and sanitized reports for user-assisted testing.

Improvements
- Each backend polls and processes commands independently, retaining existing detailed ROG controls.
- Logitech receiver device names and types are queried; device preferences and order are preserved after identity is confirmed.
- Coarse battery readings can fall back to an available feature that reports an exact percentage.

Fixes
- Fixed invalid battery replies being shown as 0%.
- Fixed duplicate device cards after temporary identity query failures.
- Fixed one backend's failure affecting other backends' readings.
- Fixed missing values in paginated Logitech DPI lists.
- Completed English translations for multi-brand device errors.
