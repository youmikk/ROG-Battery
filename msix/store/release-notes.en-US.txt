1.4.10

Feedback and diagnostics
- Rebuild feedback sessions for repeat reports, fix scrolling artifacts and reduce redraws while typing.
- Report software problems in the app without an account or manual log uploads.
- Optional diagnostics include current HID interface VID/PID values, including unsupported devices. Unrecognized-device forms request the brand and full model.
- Add error timestamps, sample ages and battery state changes. Separate identical-model interfaces and devices sharing a Logitech receiver. Preview or disable diagnostics; raw logs, serials and full local paths are excluded.

Stability fixes
- Fix Store settings, feedback storage and log-directory errors. Preserve existing settings and show errors when saving fails.
- Improve device identity isolation, reconnection and stale-battery handling; fix detection regressions affecting ROG OMNI, standard HID and Veekos devices.
- Improve Logitech DPI range detection and validation of device changes and backup restoration.
- Improve background shutdown, animation timers and drawing resource management.

Support depends on model, firmware and connection. Feedback and selected attachments are public.
