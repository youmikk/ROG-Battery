# 模拟设备测试

需要 Node.js，以及已构建的 `target/release/rog-mouse-ctl.exe`。

1. 双击 `启动模拟测试.cmd`，自动打开本地测试面板。
2. 点击“启动测试”，打开独立模拟窗口。
3. 在网页修改电量、充电、连接状态，约一秒内自动更新。

“单设备、多设备、低电量、满电 / 充电、无设备”可直接切换。测试单设备启动跳转时，先选“单设备”，再点“重新打开测试”。

面板默认地址为 `http://127.0.0.1:48763/`。测试配置和可执行文件副本保存在 `scratch/mock-panel/`。正常窗口可以同时运行，配置和托盘图标互不覆盖。模拟模式不读写真实设备，硬件参数写入需实机测试。

关闭浏览器不会停止服务。点击“停止测试”只关闭模拟窗口；点击“结束测试并关闭服务”结束整个测试服务。
