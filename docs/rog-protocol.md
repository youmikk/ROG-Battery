# ROG 鼠标私有 HID 协议（本项目实测版）

> 目标：给「多方面兼容 ROG 鼠标」做底稿。
> 来源：本机 `ROG HARPE ACE MINI`（USB `0B05:1ACE`，Omni 接收器）实测 + 逐项回读断言。
> **不是官方规格**：换型号必须重新验证每条命令，尤其 `0x51` 的子命令和寄存器号。

## 0. 传输层

- 走 HID **Feature Report**（`HidD_GetFeature` / `HidD_SetFeature`），不是 Output Report。
- 报告长 64 字节，首字节是 Report ID。
- 设备有多个顶层集合（MI_02 / MI_03 / MI_05）；参数走其中一个 vendor-defined 集合，
  灯效能力另有一个标准 **HID LampArray** 集合（UsagePage `0x59` / Usage `0x01`）。
- 读写都要「发一帧 → 读回一帧」并校验，写完要 `commit` 才落 flash（RAM 与 flash 分离）。

## 1. 读（`cmd = 0x12`）

帧形如 `{rid, 0x12, sub, p0, p1, ...}`，回帧里带对齐后的数据。

| sub | 参数 | 语义 |
|-----|------|------|
| `0x04` | `00 00` | 性能：回报率 / 去抖 / 角度吸附 / 微调 |
| `0x04` | `02 00` | DPI 四档（每档 DPI + 该档指示灯颜色） |
| `0x04` | `03 00` | 四档颜色（部分型号单独可读） |
| `0x00` | `00 00` | 当前档位（profile / active stage） |
| `0x07` | `00 00` | 能量：电量 / 电压 / 充电状态 / 休眠 / 低电量阈值 / 充满效果 |
| `0x06` | `00 00` | 抬起距离 LOD（Low / High） |
| `0x03` | `zone 00` | 灯效（mode / 亮度 / RGB） |
| `0x05` | `00 00` | 按键绑定表 |
| `0x12` | `02 00` | 设备信息（型号 / SN / 固件） |

## 2. 写

### 2.1 寄存器文件：`0x51 / 0x31`
```
{rid, 0x51, 0x31, REG, 0x00, VALUE...}
```
- `REG = 1..4` → 第 N 档 DPI：`VALUE = dpiLo, dpiHi, R, G, B`（同一帧写值 + 该档灯色）
- `REG` 其它值对应其它寄存器（按型号不同，需实测）
- 写完必须提交：

### 2.2 提交：`0x50 / 0x03`
```
{rid, 0x50, 0x03}
```
**回全零是正常**，不是 NAK。

### 2.3 能量块：`0x51 / 0x37`
```
{rid, 0x51, 0x37, 00, 00, 休眠code, 00, 低电量%, 00, 充满效果}
```
⚠️ 读写偏移不同：写 `tail[n]` ↔ 读 `aligned[n+4]`。
样例 `51 37 00 00 04 00 14 00 01` = 10 分钟 / 20% / 充满效果开。

### 2.4 LOD：`0x51 / 0x35`（独立命令族）
```
{rid, 0x51, 0x35, 0xFF, 0x00, 0xFF, code}   // code 0=Low 1=High
```
⚠️ 厂商承认：**会重置表面标定**，没有「只设 LOD」的命令。

### 2.5 灯效（私有）：`0x51 / 0x28`
```
{rid, 0x51, 0x28, zone, 00, mode, brightness, R, G, B, dir, random, speed}
```
- 本型号 `zone` 恒 0；`dir/random/speed` 只对 Rainbow/Comet 有意义，本型号不支持 → 恒 0。
- **注意**：本型号同时是标准 HID LampArray 设备，Windows 11「动态光效」可以直接控；
  私有通道和系统通道**会互相打架**，本项目默认交给系统，不再写私有报文。

### 2.6 按键：`0x51 / 0x21`
```
{rid, 0x51, 0x21, 00, 00, srcLo, srcHi, dstLo, dstHi}
```
`src` 是物理键固定码（不可改），`dst` 是动作码；**`dst = 0x0000` = 禁用该键**。

## 3. 能力差异（按型号）

本机（HARPE ACE MINI）已确认：

| 项 | 状态 |
|----|------|
| DPI 四档 + 每档颜色 | ✅ |
| 回报率 125/250/500/1000 | ✅ |
| 去抖 0~7（0=关，1..7 = 8..32ms） | ✅ |
| 角度吸附 / 角度微调 | ✅ |
| 休眠 / 低电量阈值 / 充满效果 | ✅ |
| LOD | ✅（代价：重置表面标定） |
| 按键重映射 | ✅（危险，需 `--yes`） |
| 加减速曲线 | ❌ 本型号不支持 |
| 灯效 | ⚠️ 走 Windows 动态光效（1 个灯珠，鼠标类） |
