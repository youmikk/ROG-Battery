# 界面语言

设置页顶部的「语言」提供「跟随系统 / 中文 / English」。旧配置缺少语言项时按系统语言启动。

`settings.ini` 中的 `language` 接受 `system`、`zh-CN` 和 `en`。跟随系统读取 Windows 用户显示语言（`GetUserDefaultUILanguage`）；中文地区使用简体中文，其他语言回退到英文。手动切换在保存成功后立即生效。

中英文文案集中在 `src/i18n/catalog.rs`。静态文案使用 `tr!`，带参数的完整句子使用 `trf!`，中英文分支都由 Rust 检查格式参数。新增文案应同时补齐两个版本，避免拼接句子。`translate` 仅在已知的协议标签与缓存说明边界使用，不处理设备名称、路径或用户输入。

下拉列表按语言分别缓存，但选项值与顺序保持一致。续航估算保留原始数据，在绘制时生成当前语言的文案；设备通信与配置键不随语言变化。Windows 文件选择器的系统控件和底层系统错误仍由 Windows 提供。

验证覆盖系统语言解析、配置往返、切换后的下拉缓存、缓存估算翻译，以及 720px / 1100px 英文页面渲染与命中区域。
